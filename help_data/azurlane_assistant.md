| 指令   | 格式                         | 示例                    | 说明                       |
| ------ | ---------------------------- | ----------------------- | -------------------------- |
| `/az`  | `/az help`                   | `/az help`              | 查看本帮助菜单             |
| `/az`  | `/az <UID> <服务器>`         | `/az 749633679 111`     | 查询指定指挥官详情         |
| `/azb` | `/azb <UID> <服务器> [数量]` | `/azb 749633679 111 50` | 查询建造记录（默认10条）   |
| `/azs` | `/azs <名称或ID>`            | `/azs 地狱犬行动`       | 查询服务器对应的 ID 或名称 |
